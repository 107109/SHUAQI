# 幼专耍起饮食 · 静态网站部署包

这是一个**标准静态网站**文件夹，上传到任意免费静态托管平台即可生成一个可点击的网址（链接条），转发到 QQ 群 / 微信，谁点谁用，无需登录。

## 文件夹内容（整包一起上传，别拆开）
- `index.html` —— 网站主页与全部逻辑
- `data_1.js` / `data_2.js` —— 一食堂 / 二食堂菜单数据
- `*.webp` —— 全部店铺展示图、封面、收款码（根目录平铺；WebP 压缩 + 懒加载 + 骨架屏，首屏数秒即出）

## 三种免登录部署方式（任选其一，1 分钟搞定）

### 方式一：Netlify Drop（最推荐，最稳）
1. 浏览器打开 https://app.netlify.com/drop
2. 把**本文件夹里所有文件**拖进去
3. 几秒后自动生成 `https://xxxx.netlify.app` 的网址，复制发群里即可

### 方式二：Vercel
1. 打开 https://vercel.com/new
2. 选择「Upload」或直接拖入本文件夹所有文件
3. 部署完成得到 `.vercel.app` 网址

### 方式三：GitHub Pages
1. 在 GitHub 新建一个仓库，把本文件夹所有内容 push 上去
2. 仓库 Settings → Pages → 选择 main 分支根目录 → Save
3. 等待约 1 分钟，得到 `https://你的用户名.github.io/仓库名/` 网址

## 注意事项
- 必须**整包上传**（所有文件放同一目录），拆开会图裂。
- 图片已用相对路径引用，部署后自动适配，无需改任何代码。
- 评分 / 投票保存在每位访客自己的浏览器里（localStorage）；如需「全班共享同一份实时榜单」，需要后端数据库，可另行接入。
- 本文件夹可离线双击 `index.html` 预览，但**图片要走 http 服务或部署后才稳定显示**，直接 file:// 双击在部分浏览器里也能看，但部署成网址最稳。
