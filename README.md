# 幼专耍起饮食 🍜

校园食堂「幼专耍起饮食」趣味点单小程序 —— 随便转盘选饭、菜品店铺八档评分、背包投票出豆瓣分、店铺图片墙、管家妈麽饮食规划。

## 这是什么
- 一个**纯静态网页**，所有图片已内嵌进 `index.html`，无需服务器、无需数据库、无需联网加载图片。
- 打开即用：双击 `index.html` 即可在浏览器离线运行；部署到 GitHub Pages 后，任何人都可通过链接访问。

## 功能
1. **随便转盘**：不知道吃啥？转一下，命运帮你选。
2. **八档评分**：9.9 仙品佳肴 / 9.0 夯爆了 / 8.5 美味 / 7.0 人上人 / 6.0 NPC / 5.0 一般 / 4.0 拉完了 / 1.0 shit，每人每菜限评一次。
3. **背包投票**：好评 + 差评 → 自动换算豆瓣式评分。
4. **店铺图片墙**：一食堂 / 二食堂全部菜单原图展示。
5. **管家妈麽饮食规划**：填生活费、餐数、预算、想存的零花钱，生成月 / 周 / 日 / 单餐规划。

## 本地预览
直接双击 `index.html` 用浏览器打开即可。

## 部署（GitHub Pages）
把本仓库的 `index.html` 与 `.nojekyll` 传到 GitHub，在仓库 **Settings → Pages** 中选择 `main` 分支、`/(root)` 目录，保存后即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。

> `.nojekyll` 的作用：告诉 GitHub 不要对网站做额外的静态生成处理，确保文件原样发布。

## 更新网站
改完 `index.html` 后，重新上传覆盖即可；GitHub Pages 一般 1 分钟内自动刷新。
